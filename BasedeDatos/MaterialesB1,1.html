Materiales de Estudio — Tema 1.1: Introducción a Bases de Datos

Información del Tema y Conceptos Clave

Una base de datos es un repositorio estructurado que permite almacenar, organizar y consultar grandes volúmenes de información de forma electrónica, rápida y segura.

1. Datos vs Información: Los datos son hechos aislados; la información surge cuando esos datos se procesan y estructuran para darles sentido.

2. SGBD (Sistema de Gestión de Bases de Datos): Software intermediario (como MySQL o PostgreSQL) que garantiza la integridad, seguridad y respaldo de la información.

3. Relacionales vs NoSQL: Las relacionales organizan datos en tablas con propiedades ACID; las NoSQL manejan esquemas flexibles para Big Data.
