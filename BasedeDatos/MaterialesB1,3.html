Materiales de Estudio — Tema 1.3: Lenguaje SQL y Consultas

Información del Tema y Conceptos Clave

SQL (Structured Query Language) es el lenguaje estándar para interactuar y administrar bases de datos relacionales.

1. DDL (Definición): Comandos como CREATE, ALTER y DROP para la estructura.

2. DML (Manipulación): Comandos como SELECT, INSERT, UPDATE y DELETE para los registros.

3. Consultas Avanzadas: Uso de uniones como INNER JOIN, LEFT JOIN y agrupamientos con GROUP BY.
