Materiales de Estudio — Tema 2.1: Arquitecturas de Software (Monolitos, MVC y Microservicios)

Información del Tema y Conceptos Clave

1. Patrón MVC (Modelo-Vista-Controlador): Separa la lógica de negocios (Modelo), la interfaz de usuario (Vista) y el flujo de control (Controlador).

2. Aplicaciones Monolíticas: Sistemas diseñados como una sola unidad cohesiva y autocontenida.

3. Microservicios: Estilo arquitectónico que estructura una aplicación como un conjunto de servicios pequeños e independientes.
